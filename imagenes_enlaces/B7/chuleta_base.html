Chuleta de HTML y CSS básico

Estructura

<!DOCTYPE html> <html lang="es"> <head> ... </head> <body> ... </body> </html>

En el head: meta charset="utf-8", title y meta author.

Texto

Encabezados h1 a h6, párrafo p, salto br y línea hr (br y hr no se cierran).

Formato: b/strong, i/em, mark, small, del, ins, u, sub y sup. Comentario: <!-- texto -->.

Estilos con style

color, background-color, font-size, font-family, text-align y border (por ejemplo 5px solid green).

Se escribe propiedad:valor; (dos puntos y punto y coma). Colores: nombre, rgb, hex y hsl.

Imágenes

<img src="ruta" alt="texto"> (no se cierra). Tamaño con style="width:200px; height:150px;".

float: left, right o none. Formatos: JPG, PNG, GIF, SVG e ICO.

Enlaces

<a href="destino" target="_blank">rótulo</a>. El rótulo puede ser texto, imagen o ambos.

Absoluto: URL completa. Relativo: ruta desde la página (imagenes/logo.jpg).
