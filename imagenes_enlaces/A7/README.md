# Nivel 2 · A7. ¿Qué verá el usuario?

- **(a)** La imagen del gato aparece **a la derecha** de la página y el párrafo la rodea: el texto se coloca a su izquierda, porque `float: right`.
- **(b)** Si `gato.jpg` no existe, se muestra el texto alternativo **"Gato durmiendo"**, normalmente junto a un icono de imagen rota.
- **(c)** Al hacer clic en el logo se abre **https://www.w3.org/** en una **pestaña nueva** (`target="_blank"`), porque el logo es el rótulo del enlace.
