# Nivel 2 · A1. Verdadero o falso

| N.º | V / F | Corrección (si es falsa) |
|---|---|---|
| 1 | F | `<img>` es una etiqueta vacía: no lleva etiqueta de cierre ni `</img>`. |
| 2 | V | El atributo `alt` muestra su texto cuando la imagen no se puede cargar (y lo leen los lectores de pantalla). |
| 3 | V | `style` tiene prioridad y evita que una hoja de estilos cambie el tamaño de la imagen. |
| 4 | V | `float` admite `left`, `right` y `none`. |
| 5 | F | El rótulo de un enlace puede ser un texto, una imagen o ambas cosas a la vez. |
| 6 | V | `target="_blank"` abre el destino en una pestaña o ventana nueva. |
| 7 | F | Por defecto un enlace **por visitar** se ve azul y uno **ya visitado**, morado. |
| 8 | F | El enlace relativo no incluye el dominio, solo la ruta desde la página actual. El que escribe la URL completa es el **absoluto**. |
