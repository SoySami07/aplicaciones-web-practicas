# Práctica 1. Reflexión previa

1. Cada párrafo va con la etiqueta `<p>` y la justificación se consigue con la propiedad CSS `text-align: justify;`.
2. Para marcar solo una parte de un párrafo sirven `<span>` con estilo, `<i>` o `<em>` para la cursiva y `<b>` o `<strong>` para la negrita.
3. Para que un mismo sentimiento tenga siempre el mismo color hice antes una lista de sentimientos y colores (por ejemplo, locura: darkorange, amor: crimson) y la usé siempre igual.
