# A6. ¿Qué verá el usuario?

## Predicción
1. Un título grande y en negrita: **Resumen de la jornada** (`<h1>`).
2. Un párrafo en dos líneas: "Ha ganado el equipo local." y, debajo, por el `<br>`, "El rival se despide del torneo."
3. Una línea horizontal de lado a lado (`<hr>`).
4. Un encabezado pequeño en negrita: **Próximo partido** (`<h4>`).
5. Un párrafo: "Sábado a las 18:00".
