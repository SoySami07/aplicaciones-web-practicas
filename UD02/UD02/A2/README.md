# A2. Relaciona etiqueta y efecto

| Etiqueta | Efecto |
|---|---|
| 1. `<mark>` | **B** (texto remarcado, como un fosforito) |
| 2. `<del>` | **A** (texto tachado) |
| 3. `<sub>` | **E** (subíndice, como H₂O) |
| 4. `<sup>` | **F** (superíndice, como m²) |
| 5. `<small>` | **D** (texto más pequeño) |
| 6. `<em>` | **C** (texto enfatizado, cursiva) |
| 7. `<ins>` | **G** (texto insertado, subrayado) |

Resultado: 1-B, 2-A, 3-E, 4-F, 5-D, 6-C, 7-G.
